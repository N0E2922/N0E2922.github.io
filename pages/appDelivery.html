Burguezza App

Plataforma de pedidos a domicilio que conecta a los clientes con una interfaz rápida hecha en Ionic y un backend en Laravel robusto para la gestión de órdenes.


Tecnologías utilizadas: Laravel, Php, Ionic, MySQL.

  • Catálogo dinámico con categorías, buscador de productos en tiempo real y gestión interactiva de carrito de compras.
  • Sistema de autenticación de usuarios, historial de pedidos y un flujo de checkout con cálculo automático de impuestos y envío.
  • Panel para el control total de productos(CRUD), gestión de imágenes y administración de estados de órdenes.
  • Integración de una API REST para la sincronización inmediata entre la base de datos y la aplicación móvil.
